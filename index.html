📋 Comment télécharger votre historique Netflix ?

  1. Connectez-vous sur netflix.com
  2. Menu → Compte → Profil → Accès aux données
  3. Télécharger → Historique de visionnage
  4. Attendez l'email, puis importez ici le CSV

🎬 Comment exporter votre historique Prime Video ?

  1. Allez sur primevideo.com → Historique
  2. Ouvrez la console DevTools (F12 → Console)
  3. Collez le script prime-video-export.js et appuyez sur Entrée
  4. Le CSV se télécharge automatiquement
